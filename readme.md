# Parrilla televisiva para RTVE

<!-- manifiesto:inicio -->
## Declaración de intenciones

La televisión pública también toma partido cuando presenta una mirada ideológica como si fuera neutral. Ahí están los títulos, enfoques y objetivos de programas de la televisión actual que, a juicio de este proyecto, se inclinan claramente a la izquierda. No hay mas que considerar cualquiera de los siguientes ejemplos:
- [**Cara al Show**](https://es.wikipedia.org/wiki/Cara_al_show) (en clara mofa al conocido "_Cara al Sol_"), programa en el que se percibe, desde el titulo hasta en los contenidos, un tinte politico izquierdista populista
- [**Al cielo con ella**](https://es.wikipedia.org/wiki/Al_cielo_con_ella) (haciendo mofa al dicho común en la Semana Santa, siendo cualquier evento religioso católico algo peleado con la actual izquierda)
- [**El Perro Andaluz by Manu Sanchez**](https://es.wikipedia.org/wiki/El_perro_andaluz_by_Manu_S%C3%A1nchez) (haciendo especial hincapié en las palabras _Perro Sanchez_, como claro acto de self-labeling ante el otrora despectivo _PerroSanxe_)
- [**¡Cuánta Guerra!**](https://es.wikipedia.org/wiki/%C2%A1Cu%C3%A1nta_guerra!) (publirreportaje de la guerra civil para mantener viva la crispacion y polarización social con una guerra que sucedió hace casi un siglo).
- [**Los archivos secretos del NO-DO**](https://es.wikipedia.org/wiki/Los_archivos_secretos_del_NO-DO) (una vez más, un reportaje atacando unicamente a un lado de la historia, interesado en mantener la crispación en la sociedad).

Este proyecto propone devolver el golpe con el mismo ejercicio, pero en sentido contrario: una parrilla ficticia que lleva esa lógica hasta el exceso, cambia el signo de la provocación y aplica un pendulazo social de proporciones deliberadamente desmedidas. No pretende ofrecer una programación real (o sí?) ni una alternativa neutral (seguro que no); es sátira política, espejo deformante y réplica a lo que sus autores perciben como sesgo en la pantalla pública.

Como expresa la premisa original, no se trata de imaginar «qué mierda de televisión saldrá si ganan los fachas», sino de exagerar como reacción a «la mierda de televisión que dejan los rojos» y aplicar una contrapartida ideológica imaginaria a la actual programación. 

Es relevante mencionar que, para poder llevar a cabo este proyecto, a la IA que se ha utilizado para facilitar la escritura, ha sido necesario explicar de manera explicita que la sátira no pretende ofender a los votantes de derechas (como siempre tendía a hacer): el objetivo del proyecto es que escueza especialmente al lado progresista y al «psoe-state-of-mind».

## Organización

Las fichas de programas están en la carpeta [programas](programas/) y las de las personas, en [rostros](rostros/); ambas se enlazan desde las tablas anteriores. Cada ficha identifica el tipo de programa y las personas asignadas cuando esa información está disponible; los apartados todavía no definidos pueden completarse más adelante. Las ideas de partida están en [conversaciones/chatgpt.md](conversaciones/chatgpt.md).

### Actualización de la parrilla

Cada archivo Markdown de `programas` debe incluir estos campos, uno por línea:

```markdown
- **Título:** Nombre del programa
- **Tipo:** Tipo de programa
- **Estado:** Confirmado
- **Horario:** 16:00-18:00
- **Presentador:** Nombre del presentador
- **Reemplaza:** Programa actual al que sustituye
- **Descripción:** Descripción breve para la parrilla.
```

El estado debe ser `Confirmado` o `Candidato`. El campo `Presentador` es opcional: si todavía no está asignado, la tabla muestra «Por concretar». El campo `Reemplaza` también es opcional: indica a qué programa de la televisión actual sustituye, y en la web solo aparece al final de la página del programa. Las tablas de programas de este README se generan a partir de estas fichas; no hay que editar las filas entre sus marcadores.

El campo `Horario` es obligatorio y usa el formato de 24 horas `HH:MM-HH:MM`. Si la hora final es anterior a la inicial, termina al día siguiente (por ejemplo, `23:00-01:00`). Las tablas se ordenan por hora de inicio, desde las 00:00; a igualdad de hora, por título.

Las tablas de personas también se generan, a partir de las fichas de la carpeta `rostros`. Cada una lleva estos campos:

```markdown
- **Nombre:** Nombre de la persona o del grupo
- **Perfil:** Presentador / colaborador
- **Estado:** Confirmado
- **Programas:** [Título del programa](../programas/ficha.md), [Otro](../programas/otra.md)
- **Descripción:** Descripción breve para la tabla y la web.
```

`Estado` es `Confirmado` (en plantilla) o `Candidato` (en la recámara). `Programas` es opcional, pero si se rellena debe enlazar a fichas existentes de `programas`; si un enlace no lleva a ninguna ficha, el generador falla. Debajo de los campos se puede escribir una biografía libre en Markdown.

Para actualizar las tablas localmente, ejecuta `python scripts/actualizar_parrilla.py`. Para comprobar que están al día sin modificarlas, añade `--check`. Al subir a `main` cambios de las fichas, la parrilla, el generador o su workflow, GitHub Actions ejecuta el generador y, si es necesario, publica un commit de `github-actions[bot]` con la parrilla actualizada. Para ello, el repositorio debe permitir que las Actions escriban en el contenido y la rama debe admitir ese commit.

### Web: el FACHATEXTO

La parrilla también se publica como una web con estética de teletexto en [ggonmar.github.io/nueva_rtve](https://ggonmar.github.io/nueva_rtve/). Se navega tecleando números de página de tres cifras (con el teclado o el mando en pantalla), con los botones de colores y con las flechas:

| Página | Contenido |
| --- | --- |
| 100 | Portada: qué se emite ahora, qué viene después, una noticia de última hora al azar y más titulares |
| 101 | Manifiesto (el texto de este README entre los comentarios `manifiesto:inicio` y `manifiesto:fin`) |
| 199 | Ayuda: guía de páginas, teclas y mapa completo |
| 200 | Parrilla completa |
| 201-299 | Una página por programa: primero los confirmados por hora de inicio y después los candidatos |
| 300 | Índice de noticias, agrupadas por sección |
| 301-399 | Una página por noticia, de la más reciente a la más antigua |
| 400 | Rostros de la cadena: en plantilla y en la recámara |
| 401-499 | Una página por rostro, con su foto y enlaces a sus programas |
| 500 | Subvencionómetro |
| 555 | Buscador: programas, noticias, presentadores y páginas, con resultados según se escribe |

Todas las páginas se pueden compartir con el botón «Compartir» del televisor, el botón ⇪ del mando o la tecla C. Se puede copiar el enlace, usar el menú de compartir del dispositivo, o copiar al portapapeles o descargar un pantallazo PNG de la página completa. El pantallazo se genera en el navegador con [modern-screenshot](https://github.com/qq15725/modern-screenshot), que se carga bajo demanda. La fuente VT323 se sirve desde `web/fuentes/` (licencia OFL).

Cada programa tiene también una dirección fija basada en el nombre de su ficha, por ejemplo `#/el-cabestrillo` para `programas/el-cabestrillo.md`. Para añadir la imagen representativa de un programa, guárdala como `imagenes/programas/<dirección>.jpg` (también valen `.png`, `.webp`, `.gif` y `.svg`); mientras no exista, la ficha muestra una carta de ajuste con la ruta esperada.

Los rostros funcionan igual: cada uno tiene la dirección `#/rostros/<nombre-de-la-ficha>` y su foto va en `imagenes/rostros/<nombre-de-la-ficha>.jpg` (o en cualquiera de los formatos anteriores). Por ejemplo, `imagenes/rostros/bertin-osborne.png` para `rostros/bertin-osborne.md`. Las páginas de los programas enlazan a sus rostros, y las de los rostros, a sus programas.

En las fichas de programas, de rostros y en las noticias, todo lo que vaya a partir de un título `# Notas` (de cualquier nivel) es interno: se queda en el repositorio y no aparece en la web. Sirve para fuentes, ideas descartadas o comentarios del equipo.

Las noticias están en la carpeta [noticias](noticias/), una por archivo Markdown. Cada vez que se carga la web, la portada muestra una al azar en «Última hora». Cada noticia empieza con estos campos, uno por línea, seguidos del cuerpo en Markdown:

```markdown
- **Titular:** Titular de la noticia
- **Sección:** Nacional
- **Fecha:** 2026-11-17
- **Firma:** Redacción FACHATEXTO
- **Entradilla:** Resumen de una o dos frases.
```

Todos los campos son obligatorios salvo `Firma`, y la fecha usa el formato `AAAA-MM-DD`. Las noticias se mantienen dentro del enfoque del proyecto: sátira que escueza al PSOE y al «psoe-state-of-mind», sin herir a conservadores ni liberales. Deben estar redactadas como una noticia de agencia, pero con un absurdo evidente que no deje dudas de que son ficción.

La web se genera con `python scripts/construir_web.py` a partir de las fichas, las noticias, este README y los archivos estáticos de `web/`, y se deja en `_site/` (no se versiona). Para verla en local, ejecuta después `python -m http.server --directory _site` y abre `http://localhost:8000`. Al subir cualquier cambio a `main`, el workflow «Publicar web» la construye y la despliega en GitHub Pages; en la configuración del repositorio, *Settings › Pages › Source* debe estar en «GitHub Actions».
