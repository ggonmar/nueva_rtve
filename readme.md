# Parrilla televisiva para RTVE

## Declaración de intenciones

La televisión pública también toma partido cuando presenta una mirada ideológica como si fuera neutral. Ahí están los títulos, enfoques y objetivos de programas de la televisión actual que, a juicio de este proyecto, se inclinan claramente a la izquierda. No hay mas que considerar cualquiera de los siguientes ejemplos:
- [**Cara al Show**](https://es.wikipedia.org/wiki/Cara_al_show) (en clara mofa al conocido "_Cara al Sol_"), programa en el que se percibe, desde el titulo hasta en los contenidos, un tinte politico izquierdista populista
- [**Al cielo con ella**](https://es.wikipedia.org/wiki/Al_cielo_con_ella) (haciendo mofa al dicho común en la Semana Santa, siendo cualquier evento religioso católico algo peleado con la actual izquierda)
- [**El Perro Andaluz by Manu Sanchez**](https://es.wikipedia.org/wiki/El_perro_andaluz_by_Manu_S%C3%A1nchez) (haciendo especial hincapié en las palabras _Perro Sanchez_, como claro acto de self-labeling ante el otrora despectivo _PerroSanxe_)
- [**¡Cuánta Guerra!**](https://es.wikipedia.org/wiki/%C2%A1Cu%C3%A1nta_guerra!) (publirreportaje de la guerra civil para mantener viva la crispacion y polarización social con una guerra que sucedió hace casi un siglo).
- [**Los archivos secretos del NO-DO**](https://es.wikipedia.org/wiki/Los_archivos_secretos_del_NO-DO) (una vez más, un reportaje atacando unicamente a un lado de la historia, interesado en mantener la crispación en la sociedad).

Este proyecto propone devolver el golpe con el mismo ejercicio, pero en sentido contrario: una parrilla ficticia que lleva esa lógica hasta el exceso, cambia el signo de la provocación y aplica un pendulazo social de proporciones deliberadamente desmedidas. No pretende ofrecer una programación real (o sí?) ni una alternativa neutral (seguro que no); es sátira política, espejo deformante y réplica a lo que sus autores perciben como sesgo en la pantalla pública.

Como expresa la premisa original, no se trata de imaginar «qué mierda de televisión saldrá si ganan los fachas», sino de exagerar como reacción a «la mierda de televisión que dejan los rojos» y aplicar una contrapartida ideológica imaginaria a la actual programación. 

Es relevante mencionar que, para poder llevar a cabo este proyecto, a la IA que se ha utilizado para facilitar la escritura, ha sido necesario explicar de manera explicita que la sátira no pretende ofender a los votantes de derechas (como siempre tendía a hacer): el objetivo del proyecto es que escueza especialmente al lado progresista y al «psoe-state-of-mind».

## Organización

Las fichas están en la carpeta [programas](programas/) y se enlazan desde las tablas anteriores. Cada ficha identifica el tipo de programa y las personas asignadas cuando esa información está disponible; los apartados todavía no definidos pueden completarse más adelante. Las ideas de partida están en [conversaciones/chatgpt.md](conversaciones/chatgpt.md).

### Actualización de la parrilla

Cada archivo Markdown de `programas` debe incluir estos campos, uno por línea:

```markdown
- **Título:** Nombre del programa
- **Tipo:** Tipo de programa
- **Estado:** Confirmado
- **Horario:** 16:00-18:00
- **Presentador:** Nombre del presentador
- **Descripción:** Descripción breve para la parrilla.
```

El estado debe ser `Confirmado` o `Candidato`. El campo `Presentador` es opcional: si todavía no está asignado, la tabla muestra «Por concretar». Las tablas de programas de este README se generan a partir de estas fichas; no hay que editar las filas entre sus marcadores. Las tablas de personas y asignaciones se mantienen manualmente.

El campo `Horario` es obligatorio y usa el formato de 24 horas `HH:MM-HH:MM`. Si la hora final es anterior a la inicial, termina al día siguiente (por ejemplo, `23:00-01:00`). Las tablas se ordenan por hora de inicio, desde las 00:00; a igualdad de hora, por título.

Para actualizar las tablas localmente, ejecuta `python scripts/actualizar_parrilla.py`. Para comprobar que están al día sin modificarlas, añade `--check`. Al subir a `main` cambios de las fichas, la parrilla, el generador o su workflow, GitHub Actions ejecuta el generador y, si es necesario, publica un commit de `github-actions[bot]` con la parrilla actualizada. Para ello, el repositorio debe permitir que las Actions escriban en el contenido y la rama debe admitir ese commit.
